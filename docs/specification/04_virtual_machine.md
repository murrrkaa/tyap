# Спецификация виртуальной машины MLT
Виртуальная машина MLT является стековой: все операнды передаются через стек значений.  
Программа представляется в виде последовательности инструкций, которые выполняются последовательно.

![Структура виртуальной машины](/tyap/img/virtual-machine.png)
## Структура текущей VM

* **MltVm** — исполнительный цикл `fetch/decode/execute`.
* **Instructions** (`IReadOnlyList<Instruction>`) — массив инструкций.
* **InstructionPointer** (`_instructionPointer`) — индекс текущей инструкции.
* **EvaluationStack** (`Stack<Value>`) — стек для хранения данных.
* **Variables** (`Dictionary<string, Value>`) — хранилище переменных.
* **BuiltinFunctions** — реализация встроенных функций.
* **Environment** (`IEnvironment`) — интерфейс для ввода-вывода.
* **ExitCode** (`_exitCode`) — код завершения программы

## Инструкции

Каждая инструкция программы содержит:
1.  **Код инструкции** из набора `InstructionCode`;
2.  **Значение операнда**, представленное типом `Value` (необязательное).

### Условные обозначения
*   Операнд указывается в квадратных скобках, например: `[Value]`;
*   Вершина стека вычислений обозначается **EVAL[^1]**, следующее за ней значение — **EVAL[^2]**, и так далее;
*   Каждая инструкция имеет свой индекс, нумерация начинается с **0**.

### Типы данных в `Value`, поддерживаемые машиной:
* `Int` (`long`)
* `Float` (`decimal`)
* `String` (`string`)
* `Unit` (пустое значение)

## Набор инструкций

### Стек и константы

| Инструкция       | Описание                                             |
|------------------|------------------------------------------------------|
| **Push [Value]** | Добавляет значение операнда на стек вычислений.      |
| **Pop**          | Удаляет значение со стека вычислений (**EVAL[^1]**). |

### Переменные

| Инструкция           | Описание                                                                                            |
|----------------------|-----------------------------------------------------------------------------------------------------|
| **DefineVar [Name]** | Записывает в новую переменную с именем `[Name]` значение **EVAL[^1]**. Снимает значение со стека.   |
| **StoreVar [Name]**  | Записывает в ранее созданную переменную `[Name]` значение **EVAL[^1]**. Снимает значение со стека.  |
| **LoadVar [Name]**   | Читает значение переменной `[Name]` и помещает его в стек вычислений.                               |

### Арифметические операции

| Инструкция   | Описание                                                                                                                                            |
|--------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| **Add**      | Выполняет операцию сложения (если оба операнда типа `string` - конкатенацию): `EVAL[^2] + EVAL[^1]`. Снимает два значения, результат кладет в стек. |
| **Subtract** | Выполняет операцию вычитания: `EVAL[^2] - EVAL[^1]`. Снимает два значения, результат кладет в стек.                                                 |
| **Multiply** | Выполняет операцию умножения: `EVAL[^2] * EVAL[^1]`. Снимает два значения, результат кладет в стек.                                                 |
| **Divide**   | Выполняет операцию деления: `EVAL[^2] / EVAL[^1]`. При делении на ноль вызывается исключение. Снимает два значения, результат кладет в стек.        |
| **Negate**   | Выполняет смену знака числа (унарный минус) для **EVAL[^1]**. Результат возвращает в стек.                                                          |

### Системные инструкции и управление

| Инструкция             | Описание                                                                                                                                                      |
|------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **CallBuiltin [Code]** | Вызывает встроенную функцию по её числовому коду. Операнд должен быть типа Int. <br> **Print (код 0):** извлекает **EVAL[^1]** и передает его в поток вывода. |
| **Halt**               | Останавливает работу программы. Если значение на вершине стека — число, оно приводится к `long` и сохраняется как **ExitCode**.                               |

## Валидация программы
Программа **обязательно** должна завершаться инструкцией `Halt`. В противном случае генерируется исключение `InvalidOperationException`.
