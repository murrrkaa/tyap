# Спецификация виртуальной машины MLT
Виртуальная машина MLT является стековой: все операнды передаются через стек значений.  
Программа представляется в виде последовательности инструкций, которые выполняются последовательно.

![Структура виртуальной машины](/tyap/img/virtual-machine.png)
## Структура текущей VM

* **MltVm** — исполнительный цикл `fetch/decode/execute`.
* **Instructions** (`IReadOnlyList<Instruction>`) — массив инструкций.
* **InstructionPointer** (`_instructionPointer`) — индекс текущей инструкции.
* **EvaluationStack** (`Stack<Value>`) — стек вычислений.
* **VariableScopes** (`Stack<Dictionary<string, Value>>`) — стек областей видимости переменных.
* **CallStack** (`Stack<int>`) — стек адресов возврата функций.
* **BuiltinFunctions** — реализация встроенных функций.
* **Environment** (`IEnvironment`) — интерфейс для ввода-вывода.
* **ExitCode** (`_exitCode`) — код завершения программы

## Инструкции

Каждая инструкция программы содержит:
1.  **Код инструкции** из набора `InstructionCode`
2.  **Значение операнда**, представленное типом `Value` (необязательное).

### Условные обозначения
*   Операнд указывается в квадратных скобках, например: `[Value]`;
*   Вершина стека вычислений обозначается **EVAL[^1]**, следующее за ней значение — **EVAL[^2]**, и так далее
*   Каждая инструкция имеет свой индекс, нумерация начинается с **0**.

### Типы данных в `Value`, поддерживаемые машиной:
* `Int` (`long`)
* `Float` (`double`)
* `String` (`string`)
* `Bool` (`bool`) — логическое значение.
* `Unit` (пустое значение)

## Набор инструкций
### Стек и константы

| Инструкция       | Описание                                                    |
|------------------|-------------------------------------------------------------|
| **Push [Value]** | Добавляет значение в стек вычислений.                       |
| **Pop**          | Удаляет значение с вершины стека вычислений (**EVAL[^1]**). |

### Переменные

| Инструкция    | Описание                                                                                            |
|---------------|-----------------------------------------------------------------------------------------------------|
| **DefineVar** | Забирает значение из стека вычислений, записывает его в новую переменную с указанным именем.        |
| **StoreVar**  | Забирает значение из стека вычислений, записывает его в существующую переменную с указанным именем. |
| **LoadVar**   | Читает значение переменной с указанным именем, записывает его в стек вычислений.                    |

### Арифметические операции

| Инструкция    | Описание                                                                                                                                              |
|---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Add**       | Складывает два числа на стеке вычислений (если оба операнда типа `string` - конкатенация): `EVAL[^2] + EVAL[^1]`.                                     |
| **Subtract**  | Выполняет операцию вычитания: `EVAL[^2] - EVAL[^1]`. Снимает два значения, результат кладет в стек.                                                   |
| **Multiply**  | Умножает два числа на стеке вычислений: `EVAL[^2] * EVAL[^1]`. Снимает два значения, результат кладет в стек.                                         |
| **Divide**    | Делит два числа на стеке вычислений: `EVAL[^2] / EVAL[^1]`. При делении на ноль вызывается исключение. Снимает два значения, результат кладет в стек. |
| **Not**       | Логическое отрицание (унарный НЕ) для значения на вершине стека **EVAL[^1]**. Результат возвращает в стек.                                            |

### Сравнение

| Инструкция             | Описание                                                                                                                                                              |
|------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Equal**              | Проверяет на равенство: `EVAL[^2] == EVAL[^1]`. Забирает два значения со стека вычислений и добавляет в стек булев результат проверки равенства.                      |
| **NotEqual**           | Проверяет на неравенство: `EVAL[^2] != EVAL[^1]`. Забирает два значения со стека вычислений и добавляет в стек булев результат проверки неравенства.                  |
| **Less**               | Проверяет условие меньше: `EVAL[^2] < EVAL[^1]`. Забирает два значения со стека вычислений и добавляет в стек булев результат операции "меньше".                      |
| **LessOrEqual**        | Проверяет условие меньше или равно: `EVAL[^2] <= EVAL[^1]`. Забирает два значения со стека вычислений и добавляет в стек булев результат операции "меньше или равно". |
| **GreaterThan**        | Проверяет условие больше: `EVAL[^2] > EVAL[^1]`. Забирает два значения со стека вычислений и добавляет в стек булев результат операции "больше".                      |
| **GreaterThanOrEqual** | Проверяет условие больше или равно: `EVAL[^2] >= EVAL[^1]`. Забирает два значения со стека вычислений и добавляет в стек булев результат операции "больше или равно". |

### Переходы

| Инструкция                | Описание                                                                                                                                                        |
|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Jump [Address]**        | Безусловный переход, меняет указатель инструкций. Устанавливает `InstructionPointer` в значение `[Address]`.                                                    |
| **JumpIfFalse [Address]** | Проверяет логическое значение на вершине стека (**EVAL[^1]**). Если оно равно `false`, совершает переход на указанный `[Address]`. Не снимает значение из стека |
| **JumpIfTrue [Address]**  | Проверяет логическое значение на вершине стека (**EVAL[^1]**). Если оно равно `true`, совершает переход на указанный `[Address]`.  Не снимает значение из стека |

### Управление

| Инструкция             | Описание                                                                                                                                                                                               |
|------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **CallBuiltin [Code]** | Выполняет вызов встроенной функции с указанным кодом. Забирает аргументы со стека вычислений. Возвращает результат вызова в стек вычислений.                                                           |
| **Halt**               | Завершает выполнение программы. Если стек вычислений не пуст, снимает верхнее значение и использует его как результат выполнения программы. Для значений типов Int и Float также вычисляется ExitCode. |
| **Call [Address]**     | Вызов пользовательской функции с переходом на адрес и сохранением указателя в стек возвратов.                                                                                                          |
| **Return**             | Выполняет возврат из функции: восстанавливает значение указателя инструкций из стека возвратов.                                                                                                        |     
| **PushVars**           | Добавляет новую таблицу переменных в стек таблиц переменных.                                                                                                                                           |
| **PopVars**            | Удаляет таблицу переменных со стека таблиц переменных.                                                                                                                                                 |

## Встроенные функции

| Функция        | Описание                                                                                                                                                                                                              |
|----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Print**      | Извлекает **EVAL[^1]** и передает его строковое представление в поток вывода.                                                                                                                                         |
| **ReadInt**    | Считывает строку из потока ввода и преобразует её в целое число. При ошибке формата генерирует `InvalidOperationException`. Результат кладет в стек.                                                                  |
| **ReadFloat**  | Считывает строку из потока ввода и преобразует её в число с плавающей точкой. При ошибке генерирует `InvalidOperationException`. Результат кладет в стек.                                                             |
| **ReadString** | Считывает строку из потока ввода и кладет её в стек.                                                                                                                                                                  |
| **Len**        | Извлекает строку **EVAL[^1]**, вычисляет её длину. Результат кладет в стек.                                                                                                                                           |
| **Substring**  | Извлекает количество символов `count` (**EVAL[^1]**), индекс начала `start` (**EVAL[^2]**) и строку `s` (**EVAL[^3]**). Возвращает подстроку, ограничивая переданные индексы длиной строки и результат кладет в стек. |
| **ToString**   | Извлекает значение **EVAL[^1]**, преобразует его в строку. Результат кладет в стек.                                                                                                                                   |
| **ParseInt**   | Извлекает строковое значение **EVAL[^1]** и преобразует его в целое число. При ошибке формата генерирует `InvalidOperationException`. Результат кладет в стек.                                                        |
| **ToBool**     | Извлекает числовое значение **EVAL[^1]**. Если оно отлично от нуля, возвращает `true`, иначе — `false`. Результат кладет в стек.                                                                                      |
| **ToFloat**    | Извлекает целое число **EVAL[^1]**, приводит его к числу с плавающей точкой. Результат кладет в стек.                                                                                                                 |

## Валидация программы
1. Количество инструкций в программе не должно быть равным нулю. В противном случае генерируется исключение `InvalidOperationException`.
2. Программа **обязательно** должна завершаться инструкцией `Halt`. В противном случае генерируется исключение `InvalidOperationException`.
3. `OverflowException` — Выбрасывается рантаймом при арифметических операциях с целыми числами, если результат выходит за пределы типа `Int` (`long`).
